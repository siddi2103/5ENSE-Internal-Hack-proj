- 5ENSE: Real-Time Spatial Navigation & Obstacle Avoidance

This is a demo computer vision script that uses a webcam and YOLOv8 object detection to analyze a user's surroundings in real-time. It divides the camera feed into three spatial zones (Left, Center, Right), calculates obstacle density, and determines the safest path forward. There is also a simulated GVS which will display the current required.


-- Prerequisites

To run this project, you will need **Python 3.7+** and a connected webcam.


--- Dependencies

Install the required Python libraries using 'pip':


-- in powershell

pip install opencv-python ultralytics


-> Run the program and your camera will be activated, press esc to quit.
